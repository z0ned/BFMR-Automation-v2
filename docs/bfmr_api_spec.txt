Insurance
File for Insurance
File insurance for a given shipment with specified package value. 'first_name', 'last_name', and each 'address[*]' field are all independently optional and update the name/address used for insurance — you can send just one, e.g. address[city], to update only that field. Any field left out of the request falls back to the value already saved on your account profile; if that field is also empty on your profile, the request fails with an error naming that specific field as required. 'state' is the ISO 3166-2 subdivision code without the country prefix (e.g. New Hampshire: US-NH (ISO 3166-2) - use the code suffix, NH, in this field) and 'country' is the ISO 3166-1 alpha-3 country code (e.g. United States: US (Alpha-2), USA (Alpha-3) - use the Alpha-3 form, USA, in this field).

⚠️ Warning: If you update your first_name, last_name, or any address[*] field here, this change will be saved to your account profile — it is not limited to insurance filing only. Your profile's saved details will be updated also.

first_name

First name, sent as its own field (not nested under address[]). Optional — if omitted, the first name already on your profile is used. The request fails naming this field if it's omitted and there's no name on file yet.

last_name

Last name, sent as its own field (not nested under address[]). Optional — if omitted, the last name already on your profile is used. The request fails naming this field if it's omitted and there's no name on file yet.

address[state]	
string
ISO 3166-2 subdivision code without the country prefix, e.g. New Hampshire: US-NH (ISO 3166-2), California: US-CA (ISO 3166-2) - use the code suffix, NH or CA, in this field. Must belong to the resolved address[country] (the one submitted, or the one already on your profile if address[country] is omitted) — otherwise the request fails naming this field. Optional — if omitted, the value already on your profile is used. The request fails naming this field if it's omitted and there's no value on file yet.

address[country]	
string
ISO 3166-1 alpha-3 country code, e.g. United States: US (Alpha-2), USA (Alpha-3) - use the Alpha-3 form, USA, in this field. Optional — if omitted, the value already on your profile is used. The request fails naming this field if it's omitted and there's no value on file yet.

address[zip]	
string
ZIP/postal code. Must be 5-10 characters, digits and hyphens only, e.g. 03051 or 03051-4905. Optional — if omitted, the value already on your profile is used. The request fails naming this field if it's omitted and there's no value on file yet.

My Tracker
Get My Tracker Data
Get data in My Tracker. Results include specific searches made based on keywords, date range, item status, etc.

⚠️ Upcoming change to search: Starting November 20, 2026, search will only match item name and model number. To find records more quickly by tracking number, order number, or status, switch to these filters now:
Tracking numbers: trackings[], e.g. trackings[]=1Z999AA10123456784
Order numbers: orders[], e.g. orders[]=113-1234567-1234567
Status: status, e.g. status=shipped,paid
query Parameters
page_size	
integer <int32> [ 1 .. 1000 ]
Number of items per page

page_no	
integer <int32>

string

Field to order by

order	
string
Enum: "asc" "desc"
Sort order (asc/desc)

search	
string
Search term. Before November 20, 2026 it matches part of the item name, model number, tracking number, order number, or status. Starting November 20, 2026 it matches only the item name and model number: use trackings[] for tracking numbers, orders[] for order numbers and status for statuses.

orders[]	
Array of strings <= 100 items
Filter by order number. Each value must be the whole order number as submitted with the purchase, including any dashes; case does not matter. Send it with the brackets, even for one value (orders[]=113-1234567-1234567), and repeat it for several (orders[]=113-1234567-1234567&orders[]=200012345678901), up to 100 values per request.

trackings[]	
Array of strings <= 100 items
Filter by tracking number. Each value must be the whole tracking number of the shipment; case does not matter. Send it with the brackets, even for one value (trackings[]=1Z999AA10123456784), and repeat it for several (trackings[]=1Z999AA10123456784&trackings[]=9400111899223197428490), up to 100 values per request.
